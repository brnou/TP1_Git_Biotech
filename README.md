%%writefile rapport.txt
Git est un outil de gestion de versions qui garde l'historique de chaque modification d'un projet.
Il permet de revenir à une version antérieure en cas d'erreur et de savoir qui a changé quoi, et quand.
Grâce aux branches, on peut tester une nouvelle idée sans casser la version stable du travail.
GitHub héberge le dépôt en ligne : il sert de sauvegarde et facilite le partage et le travail à plusieurs.
Dans ce TP, j'ai appris à cloner un dépôt, à créer un fichier, puis à faire add, commit et push.
J'ai aussi appris à créer une branche pour travailler séparément de la version principale.
